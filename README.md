# AI News Analyzer Agent

An AI-powered news analysis workflow built using n8n.

## Features
- Accepts a topic through a form
- Fetches recent news
- Processes and analyzes news using an LLM
- Generates a structured summary
- Sends the final analysis to the user via email

## Tech Stack
- n8n
- LLM
- News API
- Email
- Webhooks/Forms
