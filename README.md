# AI News Analyzer Agent

An AI-powered news analysis workflow built using n8n.

## Features
- Accepts a topic through a form
- Fetches recent news
- Processes and analyzes news using an LLM
- Generates a structured summary
- Sends the final analysis to the user via email

## Tech Stack
- n8n
- LLM
- News API
- Email
- Webhooks/Forms

## How to Use
1. Download the JSON workflow.
2. Open n8n.
3. Select Import from File.
4. Upload news-analyzer-agent.json.
5. Configure your own API credentials.
6. Activate the workflow.
